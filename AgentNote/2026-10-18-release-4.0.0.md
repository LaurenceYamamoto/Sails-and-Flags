# 4.0.0 リリース記録

## 収録内容

- 都市開発権を会社別の商館へ置換し、交易路の片端に自社商館を要求する。
- 倉庫による在庫中継・売買条件、荷役所の固定費と能力、商館規模による税負担軽減。
- 商館数に応じる管理費、商館管理・商館投資研究、免許取得費の調整。
- 施設の縮小・廃止（施設費の返金なし）、商館規模の一括変更、倉庫・荷役所の自動調整。
- 経路価格条件の共通既定値、未使用船・車両の一括売却、競合の運転資金・拡大判断の改善。
- 自動支出の優先順位を、買い替え → 自動増加・遭難補充 → 新規経路 → 倉庫・荷役所 → 道路権 → 商館 → 都市・道路・研究への継続投資へ統一。
- 3.xのセーブは非対応。新規ゲームから開始する。

## リリース準備

- npm・Cargoの本体とロックファイル、画面表示、ビルドスクリプト、Wasm manifest、英語ライセンスページ、現行ドキュメントの版番号を4.0.0へ更新。
- 依存ライブラリの追加なし。GPL-3.0-or-later、英語のみの法的文書を維持。
- 全テストと画面確認はローカルのみ。公開サイトは検証に使用しない。
- ローカル4193の新規ゲームで4.0.0表示、初期資金、商館タブ、更新後の投資優先順位表示を確認。ブラウザのエラーログはなし。
- リリースビルド成功。最終結果は以下の検証結果を参照。

## 公開手順

- mainと保存用4.0.0ブランチを同じコミットでGitHubへatomic pushし、リモート参照を照合する。
- 既存Sitesのproject_id・公開範囲・URLを維持し、GitHubへコミットしたソースと一致する配信ファイルを配置する。
- Sites公式ヘルパーでソースを同期・パッケージ化し、保存した版をデプロイする。
- 最終コミット・Sites版・デプロイIDはGit対象外の sites/release-4.0.0-publication.json に記録する。

## リリース確認での修正

一括投資の保存一致テストで、テスト用商館データに handling_demand と monitoring がないため、復元時に補われる既定値との差分が生じた。テスト用データへ現行の既定値を追加し、保存一致・不正入力・古い見積拒否のテストを再実行して成功。ゲーム本体の挙動は変更していない。

全247件の初回実行は244件成功、3件失敗。上記のテストデータ不足に加え、船種別集計の期待値に一括売却額が未反映、旧チュートリアルKingston–Havanaの無条件1年存続という前提が現行商館費用と不一致だった。船種別集計にsaleValueを含め、初期運営テストは既存バランス記録で黒字開始を確認した大阪–長崎へ変更（免許・商館・船を実費購入、365日、現金が初期資金を上回ることも検証）。カリブ海の採算の厳しさは既知のバランス課題として維持し、リリース作業でゲーム数値は変更しない。
