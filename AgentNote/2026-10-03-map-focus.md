# 地図の都市選択枠が巨大化する不具合

- 症状：拡大した地図で都市にフォーカスすると、太い枠が都市や周囲の地形を覆う。内蔵ブラウザのカリブ表示（約9.8倍）で巨大な枠を再現した。
- 原因：都市記号は子のmap-symbolで逆倍率補正していたが、親SVGグループのCSS outlineは地図のviewBox拡大を受けていた。ブラウザ既定のフォーカス枠と、独自のport:focus-visible枠の両方が対象になる。
- 修正：地図内の都市・自社船・競合船・競合航路のfocus時に親outlineを抑制。都市と競合船は逆倍率補正済みのhalo / ship-hitを強調する。自社船と競合航路は既存の記号・線のfocus-visible強調を維持。通常のボタン・入力・地図全体のフォーカス枠は維持する。
- 実ブラウザ確認：1.0倍、9.8倍、24.0倍で都市haloの幅は約18.693 CSS pxのまま。outline-styleはnone。都市の点のクリックで選択、Tabで次都市へ移動、Enterで選択できる。競合船のフォーカスも水色の小さな輪で表示。console警告・エラーなし。
- node --test tests/map.test.js：5件成功。CSSのみの修正であり、シミュレーションや保存形式は変更しない。
