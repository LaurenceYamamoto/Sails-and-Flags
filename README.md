# Sails & Flags

1700年をモチーフにしたブラウザ向け海陸交易シミュレーション。**P8の最初の地域拡張（西地中海）**を実装した2.0.0-alpha.1です。17港＋2内陸都市・7か国・10品目、購入3船種・馬車・研究用4船型に対応します。Genoa・Livorno、ジェノヴァ共和国・トスカーナ大公国、オリーブ油、Ligurian Companyを追加しました。

## 起動

Node.js 22以降を使用します。ライブラリのインストールやビルドは不要です。

```powershell
node scripts/serve.mjs
```

[http://127.0.0.1:4173](http://127.0.0.1:4173) をブラウザで開いてください。終了は端末で `Ctrl+C`。ポートを変更する場合は `$env:PORT=4174` を設定してから起動します。`file://` によるHTMLの直接起動は、ES Modulesの制限があるため対応していません。

## 西地中海で交易する（P8 第1地域）

1. 地図の範囲を「西地中海」に切り替え、ジェノヴァ共和国・トスカーナ大公国の免許を取得します（初期各280）。
2. GenoaとLivornoをドラッグで結ぶか、地図の巡回選択で寄港順を指定します。Genoaの織物とLivornoの食料・オリーブ油が交易機会になります。
3. Marseilleも巡る場合はフランスの免許が必要です。Genoa → Livorno → Marseilleの巡回や、より航続の長い船でLivorno–Londonへ展開できます。
4. 旧セーブのルートは積載許可を維持します。オリーブ油を運ぶ場合はルート情報の「積載条件を変更」で許可してください。新規ルートは全品目が初期選択です。

既存15港間の海上距離は1.1.0のまま維持し、新港との接続だけ経路を追加しています。新市場・新競合・外交の追加により将来の採算は変わります。全世界版の完成ではなく、次地域・キャラバン等は後続です。[更新・復旧手順](Documents/ReleaseGuide.md)を参照してください。

## 馬車で始める陸上交易（P7）

1. 地図の範囲を「欧州の道路」に切り替えます。茶色の線が道路、四角が内陸都市、丸が港です。
2. ポルトガルの免許を取得し、「新規ルート」で「陸上交易」とLisbon–Portoを選びます。地図で都市間をドラッグしてから輸送手段を切り替えることもできます。
3. 馬車の必要資金は600。同タイプの未使用車両があれば再利用します。仕入・維持費・道路通行料の運転資金は別途必要です。
4. 時間を進めると自動売買します。馬車をクリックしてルート情報を開き、積載条件、自動増減、護衛、車両追加を設定します。
5. 「陸上交易と道路」で道路開発権を購入し、整備・治安の投資日額を指定します。陸上交易技術への日額投資は馬車の維持費を減らします。0で停止し、資金不足の日は投資を見送ります。

港としてPorto、Barcelona、Marseille、内陸拠点としてMadrid、Parisを採用し、道路は8本です。各国に陸路を一律に設けるための都市追加はしません。帰路を含む全区間に道路が必要で、自動的な乗換・最短経路探索は行いません。例えばLisbon → Porto → Madrid → Cadiz → Madrid → Porto（最後はLisbonへ自動帰還）を地図の巡回選択から設定できます。距離は陸路km、海路nm。距離・市場・道路形状はゲーム用モデルです。

免許は各都市と道路の全通過国に必要です。取消時は該当ルートを解除し、残存車両を未使用へ返却、貨物・該当する都市／道路権・投資を無補償で没収します。自社の道路は通行料免除。他社の実際の通行料の20%が権利者の補助収入です。馬車と船は港の同一市場で売買し、直接荷物を受け渡しません。

現在の保存形式はv10。旧v1～v9と保全保存（P6・P7）を読み込めます。削除都市の関連ルートは解除し、残存車両を保有状態へ戻します。積荷の残存原価・削除された道路／都市開発権の取得原価・累計投資・未収分配金を返還し、移行内容を画面に表示します。新版保存と「地中海拡張前の保全保存」は別スロットを使用し、旧スロットは残します。更新前のJSON書き出しを推奨します。

## 最初の航海

1. スペインの免許を250で取得。
2. 地図でKingstonからHavanaへドラッグするか、「新規ルート」から港を指定します。
3. 「開設時の船種」でスループを指定。同船種の未使用船があれば利用し、なければ開設時に1,800で購入します。必要資金・保有資金・開設後の残金を確認し、積載条件を決めて開設します。資金・免許・航続距離が不足する場合は開設できません。
4. 「時間を進める」で連続再生。1・4・16倍速で船が滑らかに移動し、自動で仕入れ・輸送・販売・折返しを行います。「1日進める」ボタンは廃止しました。
5. 開設済みの都市間をドラッグするか、船アイコンをクリックすると、そのルートの情報を表示します。逆向きにドラッグしても同じルートを選択。ルート一覧のボタンや船アイコンのEnter/Space操作でも選べます。
6. 利益で次の船を購入し、ルート情報の「このルートに船を追加」で増便。船の追加・個別解除・積載条件・収支確認をここで行います。

都市のクリックは市場表示、都市間のドラッグはルート選択です。都市以外で離したドラッグやEsc操作は取り消しになります。ルート選択・設定入力・タブ非表示時には一時停止し、「時間を進める」で再開します。速度は再生中にも変更できます。

同じ2港は往復の向きを問わず1ルートです。積載条件・停止/再開・収支をルート単位で管理します。往復12日のルートに2隻なら各港から6日おきに出港するよう、自動で時刻表を組みます。速度が異なる船は最も遅い船に合わせた周期で間隔を調整し、速い船は港で待機します。商機のない便は見送るため、実際の間隔が延びる場合があります。

未使用船は所在地を持たず、免許・航続距離を満たす任意のルートへ配置できます。航行中は積み荷を売却して到着するまで配置解除できません。

保存は手動・自動に対応します。「保存」でブラウザ内に記録し、「再開」で手動・自動・前回世代・旧版の保存データから選びます。状態変更操作と30日ごとに自動保存します。ブラウザを閉じた間は進みません。同じブラウザ・同じURL（ホスト・ポート）で再開してください。初回起動時は常に新しい会社が表示されるため、前回の続きは「再開」を押します。保存前に読み込んだり新規設立したりする際には確認画面が出ます。

0.5.0の既存ルートは、保存された船団の先頭の船種を自動増減の初期指定として引き継ぎます。新規ルートは最初に配置する船の船種が初期値です。

v1～v9の旧セーブは読込時にv10へ自動移行します。同一経路の収支・船を統合し、継続するルートの積み荷・航海残日数を保持します。削除都市に関係する資産は上記の返還対象です。共通の積載条件は最初に作ったルートを引き継ぎ、停止中の旧ルートが含まれる経路は全体を停止します。旧保存領域を残したまま、新版は別のv10スロットに保存します。新しい都市・品目・競合を追加するため、移行後の価格推移は旧版と変わります。

## 巡回ルートと会社情報

「地図で巡回ルートを作る」を押し、都市を寄港順にクリックすると同じ港を再訪するルートを組めます（最大12回の寄港、最後の起点への帰港を除く）。例えばCadiz → Lisbon → San Juan → Santo Domingo → San Juan → Lisbonと選択すると、最後にCadizへ戻ります。最後のCadizを明示的に選んでも同じ経路になります。同じ港を連続して指定することはできません。「1港戻す」で修正し、「この寄港順で設定」から船・積載条件を指定して開設します。帰路は淡い点線で表示します。従来の新規ルートの「追加の寄港地」でも指定できます。指定順に巡回し、最後から起点へ戻ります。各港で全積み荷を売却し、翌日以降に次の港向けの商品を買い直します。全港の免許と各区間の航続距離が必要です。起点だけをずらした同順の巡回は同じルートに統合し、3港以上の逆回りは別ルートです。

ルート一覧は収益順／開設順で並べ替えられます。直近の航海が赤字なら警告を表示。帳簿は直近60明細、グラフは最大365日分の現金と総資産を表示します。3社の競合は同じ市場在庫で取引し、プレイヤーと同じ税・運営費を支払います。

地図上の水色点線と菱形船印は競合の航路・船です。クリックすると会社情報へ移動し、会社情報から地図の航路を強調できます。「競合航路を表示」で切り替えられます。

右上で日本語・English・简体中文・한국어・Français・Españolを切り替えられます。現在の都市名は全言語でアルファベット表記です。国の色印と都市の点は共通です。狭い画面では地図を横スクロールできます。

## 競合・ランキング・自動管理

「交易網の自動管理」で月間購入予算、最低保有資金、拡大・縮小の利益率を指定し、有効にして適用すると翌日から判定します。拡大閾値は縮小閾値以上にしてください。初期状態では無効です。ルート情報では個別に対象外にでき、「自動増減用の船種」で使用する船種を指定できます。航続距離を満たす船種だけを選べます。選択変更は即時保存され、翌日の判定から使われます。

自動調整は到着済み貨物の売買・税と船の維持費による利益率を使用します。未到着の仕入、免許などの会社固定費、船の購入費を判断用利益率へ混ぜません。通常の航路累計収支は従来通り別に表示します。一周分と到着実績を観測してから判定し、調整後も一周分待機します。増船は利益率の高い順で、指定船種の未使用船を優先。なければ指定船種を購入するため、事前購入は不要です。縮小は指定船種を優先し、その船種がルートにない場合は最小積載量の船を保有枠へ戻します。候補が航行中なら到着を待ち、最後の1隻は残します。

予算は暦月ごとに更新し、当月の使用額を設定変更でリセットできません。最低資金は自動購入を行う時点の制約であり、日常の維持費・交易や手動購入による減少を防ぐものではありません。実行・見送りの理由は履歴から確認できます。

資産ランキングは現金・船の価格・積み荷の取得原価で比較し、初めて単独1位になった経過日数を記録します。達成後も続行できます。小規模商人と大規模会社は毎月、市場と運営資金を比較して航路を選び、船を追加します。

競合の「買収の詳細」で代金と引継ぎ内容を確認して買収できます。価格は資産評価の115%を切り上げ、不足免許は通常価格で取得します。現金（負額なら債務）、船、積み荷、航行残日数、寄港順を引き継ぎます。同一経路は統合し、既存ルートの設定を優先。競合の過去帳簿は自社の収益に加算しません。

## 船団の一括置換・命名

「船団管理」から船種単位の全船置換と、自動増減用船種の一括変更ができます。ルート情報の「全船を置換」ではそのルートの船だけが対象です。売却額（現在の船種価格と同額）・購入/建造額・差額・残金を確認して確定します。安価な船に替えると差額を受け取れます。資金不足や航続距離不足があれば全体を変更しません。未使用船も船種単位の置換に含み、すでに置換先の船種である船は除外します。

航行中も置換できます。船名・積み荷・目的地・残日数は維持し、新しい積載量と速度を次の出港から適用します。維持費・武装・船価は即時に変更。売買は営業収支と別に記録し、運航時刻表を調整します。自動増減設定の変更は船の売買と別操作で、補充待ちの喪失船種は変更しません。

画面上部の「会社名を変更」、研究済み設計の「船種名を変更」、ルートまたは保有船一覧の「船名を変更」から改名できます。各名前は1～80文字で重複も可能。個船には帆船時代をイメージした名前を自動付与します。旧保存の無名船にも名前を表示し、改名・置換・買収・保存復元を通じて保持します。

## 海賊・護衛・外交

ルート情報の「航路の保護」で護衛を0～3隻契約できます。1隻あたり日額4で、運航停止中も発生します。護衛は襲撃率・被害率、商船の砲門数・速度は被害率を下げます。貨物とまれに船体を失い、被害額はルートと情勢履歴に残ります。新規会社・旧セーブ移行後の60日は襲撃猶予です。

「交易網の自動管理」で自動管理と「喪失船を補充する」を有効にすると、喪失した船種の未使用船を使い、なければ購入します。補充は利益率による拡大より先に共通の月間予算を使用し、最低資金を守ります。最後の船を失ってもルートを保持します。補充待ちがある間は通常の拡大を見送り、手動配置でも1隻分の待ちを解消できます。

「外交と海上の安全」で各国を開くと、友好度、取消までの余裕、前日の変化、実効税率を確認できます。日額投資と一時投入で関係を改善できます。日額0で停止、資金不足ならその日の投資を見送ります。外交投資は支出であり保有資産にはなりません。

初期友好度60、免許取得は30以上、取消警告35以下、取消20以下です。戦争が始まっただけでは免許は失われません。交易は翌日の友好度を改善しますが、交戦相手との交易は関係を悪化させます。取消時は該当国を含むルート全体が解除され、積み荷を補償なしで失い、残った船は未使用船へ戻ります。

国家間戦争は月次で確率判定します。終戦の予定日・見込みは表示せず、終戦した時点で通知します。戦時は該当国の武器需要が1.8倍になります。開戦・終戦・襲撃・免許警告は通知と履歴で確認できます。買収時は自社の友好度・免許取得条件を適用し、対象会社の外交投資設定は引き継ぎません。

v4からの移行では現金・既存市場・船団・自動管理予算を保持して武器市場を追加します。既存ルートの許可品目は保持するため、武器を扱う場合は積載条件で追加してください。喪失船補充は初期状態では無効です。

## 技術・造船・都市開発

「技術と造船」で造船技術と海上交易技術への日額投資を指定します。初期技術は0、日額0で停止、資金不足の日は見送ります。投資額が増えるほど効果は上がりますが、効率は逓減します。海上交易技術は全保有船の維持費を徐々に軽減します。

造船技術5と4,000の資金で会社の造船設備を取得できます。設計研究の基本船型はスループ（技術5）、ブリッグ（10）、フリュート（15）、コルベット（30）。積載・速度・武装・航続距離・維持費改善の5項目へ、研究時に支払う予算額を指定します。各予算の効果は逓減します。研究費は基本研究費（基本船価の25%、切上げ）＋5項目の予算合計で、研究後の残金も表示します。積載増は減速、速度・武装増は積載減を伴います。航続予算は航続距離を延ばし、維持費改善予算は整備効率を高めます。建造費・維持費は完成性能から計算し、予算額そのものによる割増はありません。

研究費を支払った時点の性能で設計が固定されます。「この設計で1隻建造」または新規ルート開設時に建造できます。設計は自動増減用船種にも指定でき、喪失時も同じ設計で補充します。技術が進んでも建造済みの船は改造せず、新たな設計を研究します。購入船・造船設備には所在地の指定がありません。0.7.0で研究済みの設計は当時の性能・建造費・維持費を保持します。

各港の市場画面に「都市開発」を追加しました。交易免許があれば国家・既存所有者から開発権を取得できます（既存所有者からの取得は割高）。規模投資は需要、生産投資はその港の得意品目の生産を増やします。物資不足は成長を止めません。カリブの投資効果は欧州より大きく、港ごとの産業特性を残したまま交易拠点を育てられます。

税収は小額の基礎収入と、実際に支払われた交易税の15%です。継続投資は「都市の継続投資一覧」から変更・停止できます。免許取消では権利と投資を補償なしで失います。買収では開発状態・権利・設計・設備を引き継ぎ、対象会社の継続投資は停止します。

開発権と造船設備は取得原価で資産評価します。技術・設計研究・都市投資は資産に加算せず、通常の営業収支と分けて帳簿に記録します。v5からの移行では既存の現金・航海・外交・乱数を保持し、技術0・投資0で開始します。

## セーブファイル

「書き出し」からJSONファイルをダウンロードし、「ファイル読込」で復元できます。選択したファイルはブラウザ内だけで読み込みます。ダウンロードが利用できない環境では、書き出し画面の補助欄からJSONをコピーして、テキストエディタで`.json`として保存できます。

ファイルの検証に失敗した場合や確認画面で閉じた場合、現在のゲームは変更しません。保存領域が不足した場合は警告を表示します。ブラウザ・ホスト・ポートが違う環境への移動にはファイル保存を使用してください。

3シード×50年、6言語の主要操作と保存復元、200隻・200航路の負荷検証を追加しました。「保全保存（P6）」は保存更新前の既存データを一度だけ保管し、通常の前回世代とは別に維持します。更新前のJSON書き出し、対応環境、性能値の再現手順と正式公開までの確認事項は[更新・復旧ガイド](Documents/ReleaseGuide.md)を参照してください。


### 海上経路と距離（1.1.0-alpha.3）

海上距離は陸地を横切らない航路上の区間距離を合計します。Marseille–Nantesはジブラルタル経由で1,708 nm、Lisbon–Nantesは724 nm。所要日数、航続判定、見積もり、競合の選定、地図の航路線と船位置に同じ経路を使います。港・河口への進入は簡略化しており、実航海向けの経路ではありません。

旧セーブの航行中の船は積荷・残日数を保持します。新しい海上距離で配置船・自動増減船種・補充待ちの航続が不足するルートは次の出港を停止し、ルート情報に理由を表示します。十分な航続の船へ置換し、自動増減設定や補充待ちを見直して「運航再開」を選んでください。強制購入や資産処分は行いません。旧保存と都市再編前の保全も読めます。
